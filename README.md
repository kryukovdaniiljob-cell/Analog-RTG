# Подбор аналогов РТГ

Инструмент подбора технического аналога по номенклатуре дивизиона РТГ.

## Что это

Одна страница, которая по любой из 5 886 позиций показывает до двух
равноценных замен из нашего же ассортимента. Данные лежат в `data.json`,
страница работает статикой и не требует сервера.

## Как устроен подбор

Позиция считается аналогом, если выполнено всё сразу:

1. тот же тип товара (первое слово наименования);
2. совпал хотя бы один размер присоединения: диаметр, резьба, DN, объём;
3. совпали ВСЕ размеры, которые есть у обеих позиций;
4. та же категория. По сборным категориям вроде «Прочее» подбор отключён.

«Замена 1» это лучший технический аналог вообще, «Замена 2» это лучший
аналог другого бренда, если первый оказался своим.

Характеристики разбираются из наименования: диаметр, толщина стенки,
резьба в дюймах, DN, исполнение ВР или НР, метрическая резьба, объём,
угол, тонкость фильтрации, материал, цвет, артикул. Дюймы и DN считаются
одной величиной.

## Навигация

Три каскадных списка: направление, группа, категория. Каждый следующий
показывает только то, что есть внутри выбранного. Плюс независимые
фильтры по бренду и по наличию замены и текстовый поиск по нескольким
словам сразу.

## Оформление

Цвета, шрифт Geist и компоненты взяты с mini-ahu.ru, логика своя.

## Обновление данных

`data.json` пересобирается из отчёта категорийной аналитики. Формат:
словари повторяющихся строк плюс массив позиций, аналог хранится номером
строки, а не копией наименования.
